# 🌸 Gratitude Chat（部署ごとの感謝共有チャット）

部署ごとに感謝を送り合える匿名チャットアプリです。  
LINEのトーク画面のように部署ごとのチャットルームが並び、  
誰でもどの部署にも入って「ありがとう」や「助かりました」などのメッセージを送れます。

---

## 💡 特徴

- 部署ごとにチャットルームを分けて表示  
- 匿名でメッセージを送信可能  
- パステルカラーの優しいデザイン  
- 履歴が保存され、過去の感謝も見返せる  

---

## 🧩 使用技術

- [Flet](https://flet.dev/)（Python製UIフレームワーク）
- Python 3.10+
- JSONファイルによる簡易データ保存

---

## 🚀 使い方

1. このリポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/ユーザー名/gratitude-chat.git
   cd gratitude-chat

2. 必要なライブラリをインストールします。
   pip install flet

3. アプリを起動します。
   flet run main.py

4. ブラウザでチャット画面が開きます。

---

## 🌸 コンセプト
このアプリは、社内で「感謝」を気軽に伝え合うための空間を目指しています。
部署ごとに雰囲気を変え、匿名で送れることで心理的安全性を守りながら、
日常の「ありがとう」を見える形にします。
